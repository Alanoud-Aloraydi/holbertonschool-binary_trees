# C - Binary Trees

# Holberton School Project

This repository contains implementations of binary tree data structures and related algorithms. It includes task-specific source files and documentation.

## Project Tasks

Task 0: New Node - Creation of a new binary tree node.  
Task 1: Insert Left - Insertion of a node as the left child.  
Task 2: Insert Right - Insertion of a node as the right child.  
Task 3: Delete - Deletion of a binary tree.  
Task 4: Is Leaf - Check if a node is a leaf.  
Task 5: Is Root - Check if a node is the root.  
Task 6: Pre-order Traversal - Traversal using the pre-order method.  
Task 7: In-order Traversal - Traversal using the in-order method.  
Task 8: Post-order Traversal - Traversal using the post-order method.  
Task 9: Height - Measure the height of a binary tree.  
Task 10: Depth - Measure the depth of a node.  
Task 11: Size - Calculate the size of a binary tree.  
Task 12: Leaves - Count the number of leaves in a tree.  
Task 13: Nodes - Count the number of nodes with at least one child.  
Task 14: Balance Factor - Measure the balance factor of a tree.  
Task 15: Is Full - Check if a binary tree is full.  
Task 16: Is Perfect - Check if a binary tree is perfect.  
Task 17: Sibling - Find the sibling of a node.  
Task 18: Uncle - Find the uncle of a node.  

## Technical Details

The project is implemented in the C language. All source code follows the Betty coding style and documentation standards.
